# WeatherPulse 🌤️

A modern, responsive weather forecast and agricultural advisory web application built with HTML, CSS, JavaScript, and the Open-Meteo API.

## Features ✨

- **Live Weather Search:** Real-time weather data for cities worldwide.
- **Geolocation Integration:** Automatic weather updates based on user location with robust permission error handling.
- **Farming & Agricultural Advisory:** Dynamic agricultural recommendations based on live rainfall, temperature, humidity, and wind conditions.
- **Interactive Metrics:** Temperature toggles (°C / °F), 7-day extended forecasts, hourly weather trends, and air quality index (AQI).
- **Offline & Cache Support:** Caches recent searches and weather queries using LocalStorage for fast response times.
- **Fully Responsive Design:** Optimized UI layouts scaled seamlessly across desktop, tablet, and mobile displays down to 360px.

## Tech Stack 🛠️

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **API:** [Open-Meteo API](https://open-meteo.com/) (Free Weather & Geocoding APIs)
- **Icons & Assets:** Custom SVG / FontAwesome icons
