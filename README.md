--------------------------------------------------
ABOUT THE PROJECT
--------------------------------------------------
WeatherPulse is a high-performance, responsive web application engineered to deliver precise real-time weather analytics and intuitive multi-day forecasts. Built with modern JavaScript standards, it provides users with dynamic atmospheric insights through a clean, accessible interface.


--------------------------------------------------
KEY CAPABILITIES
--------------------------------------------------
• Real-Time Metrics: Instant access to current temperature, humidity levels, wind velocity, and precipitation probability.

• 7-Day Forecast: Detailed multi-day atmospheric forecast to plan ahead seamlessly.

• Temperature Unit Switcher: Effortlessly toggle between Celsius (C) and Fahrenheit (F) measurement standards.

• Modern UI & Dark Mode: Visually appealing, accessible, and user-friendly interface optimized for all screens.

• Location Intelligence: Integrated city search along with direct geolocation detection.


--------------------------------------------------
TECHNICAL ARCHITECTURE
--------------------------------------------------
• Frontend Core: HTML5, CSS3, JavaScript (ES6+)
• API Integration: RESTful Weather Services
• Deployment Platform: GitHub Pages
